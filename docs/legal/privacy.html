Privacy Policy

Last updated: November 23, 2026

OwlCut is a desktop application that runs entirely on the user's own computer. There is no OwlCut server, account or cloud service: the developer does not receive, store or have access to any of the user's data.

Data OwlCut uses

  • Videos and images the user opens or creates in OwlCut. They stay on the user's computer.
  • TikTok account data, only if the user connects TikTok: the access and refresh tokens and the basic profile information returned by TikTok (display name and avatar), obtained with the user.info.basic scope. They are stored only on the user's computer, in a file readable only by the user's operating-system account.
  • App keys the user enters (for example the TikTok Client key and secret of their own developer app), stored the same way.

How the data is used

  • Profile information is used only to show the user which TikTok account is connected.
  • Tokens are used only to send to TikTok the videos the user explicitly chooses to upload (video.upload scope), and to check the status of those uploads.
  • OwlCut does not use the data for advertising, analytics or profiling, and does not sell or share it with anyone.

Data sent to third parties

When the user clicks "Send to TikTok", the selected video file is uploaded directly from the user's computer to TikTok, and is then governed by TikTok's Privacy Policy. Nothing is sent to the developer of OwlCut.

Retention and deletion

The user can disconnect TikTok at any time in OwlCut → Settings → Social accounts; this deletes the tokens and profile information from the computer and revokes OwlCut's access with TikTok. "Remove keys" also deletes the app keys. Access can also be removed in the TikTok app under Settings and privacy → Security → Manage app permissions. Uninstalling OwlCut and deleting its folder removes all of its data.

Children

OwlCut is not directed to children under 13 and does not knowingly process their data.

Changes and contact
