# Guia do OwlCut (PDF)

`OwlCut-Guia.pdf` é o guia de uso do OwlCut em português: Clips (motores Local e AI agent), Ranking, Publish (biblioteca de OwlCutVideos e envio ao TikTok) e Settings.

- Esta pasta guarda sempre **um único PDF**, o mais recente. A cada atualização do produto, o guia é revisado, ganha uma linha no "Histórico de versões" e o PDF aqui é substituído.
- A versão 1.1 foi gerada a partir de `guia-fonte.html` (HTML → PDF A4 pelo Chromium). O documento no Claude Docs (https://claude.ai/artifact/Vj5s8mcGdwzTyZ4sp4q8va) ainda está na versão 1.0.
- Versão atual: 1.1 (24/11/2026).
